# ГикКульт — учёт имущества клуба

Flask + SQLAlchemy + PostgreSQL. Регистрация участников, бронирование вещей в один клик,
QR-коды, история перемещений, админка.

## Что нового

- `/register`, `/login`, `/logout` — свои аккаунты (Flask-Login, пароли хешируются).
- Кнопка **«Забронировать»** на карточке вещи и на её странице: вещь мгновенно уходит
  в статус **«На руках»**, владельцем становится текущий пользователь.
- Кнопка **«Вернуть»** возвращает вещь туда, откуда её взяли (запомнено в брони).
- `/my` — «Мои вещи» + история своих броней.
- Таблицы `users` и `bookings`; в `items` добавлена колонка `holder_user_id`.

## Запуск локально

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # пропишите свои значения
python seed.py                  # тестовые предметы (не удаляет существующие)
python app.py
```

Открыть http://localhost:5000

Без `DATABASE_URL` приложение само поднимет SQLite-файл `geekcult.db` — удобно для локальной проверки.

## Переменные окружения

| Переменная | Зачем |
| --- | --- |
| `SECRET_KEY` | подпись сессий, обязательно свой длинный случайный ключ |
| `DATABASE_URL` | строка подключения к PostgreSQL (Railway даёт автоматически) |
| `ADMIN_LOGIN` / `ADMIN_PASSWORD` | админ-аккаунт, создаётся при старте |
| `BASE_URL` | адрес сайта для ссылок в QR-кодах |

## Деплой на Railway

1. Залить репозиторий, Railway подхватит `Procfile`.
2. В Variables добавить `SECRET_KEY`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `BASE_URL`.
   `DATABASE_URL` подставится сам от плагина PostgreSQL.
3. При старте таблицы создаются автоматически, а недостающие колонки в старой базе
   добавляются мягкой миграцией — существующие данные не теряются.

## Админка

`/admin` — доступ для пользователя с флагом `is_admin` (логин из `ADMIN_LOGIN`)
или по HTTP Basic с теми же логином/паролем.
