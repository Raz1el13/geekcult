# ГикКульт — система учёта имущества

Веб-приложение для учёта имущества клуба по локациям города.
Каждый предмет имеет QR-код, статус нахождения и полную историю перемещений.

**Авторы:** Константин Шуклин, Артём Мажаров

---

## Возможности

- Каталог предметов с фото, фильтрами по локации и доступности, живым поиском
- QR-код на каждый предмет: генерируется автоматически, ведёт на страницу вещи
- Страница печати всех QR-кодов одним листом
- Регистрация пользователей, личный кабинет с аватаром
- Бронирование со сроком от 1 до 30 дней, подсветка просрочек
- Возврат с выбором локации
- История перемещений: откуда, куда, когда и кто
- Админ-панель: добавление, редактирование, ручная смена статуса, выгрузка в CSV
- Статистика: распределение по локациям, топ предметов и пользователей

## Статусы

`Склад ЧелГУ` · `НашЭтаж` · `Хобби-Студия` · `На руках`

Список задаётся в `models.py`, константа `STATUSES`.
При изменении не забудьте поправить картинки локаций в шаблонах (см. `STATUS_IMG`).

## Запуск локально

Нужен установленный Python 3.12.

```bash
# 1. Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Файл .env в корне проекта
cat > .env << 'EOF'
SECRET_KEY=любая-длинная-случайная-строка
DATABASE_URL=sqlite:///geekcult.db
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=смените-этот-пароль
ADMIN_NAME=Администратор
EOF

# 4. Запуск
python app.py
```

Откроется на `http://127.0.0.1:5000`.
Таблицы создадутся сами при первом запуске, админ тоже.

Чтобы открыть сайт с телефона в той же сети, узнайте IP компьютера
(`ipconfig getifaddr en0` на macOS, `ipconfig` на Windows) и запустите:

```bash
flask run --host=0.0.0.0 --port=5000
```

## Переменные окружения

| Переменная | Назначение | Обязательна |
|---|---|---|
| `SECRET_KEY` | Подпись сессий. Должна быть длинной и случайной | да |
| `DATABASE_URL` | Строка подключения к базе | да |
| `ADMIN_EMAIL` | Почта администратора, создаётся при старте | нет |
| `ADMIN_PASSWORD` | Пароль администратора | нет |
| `ADMIN_NAME` | Отображаемое имя администратора | нет |
| `PORT` | Порт (задаёт хостинг) | нет |
| `TG_BOT_TOKEN` | Токен бота для уведомлений | нет |
| `TG_CHAT_ID` | Куда слать уведомления | нет |

Если Telegram-переменные не заданы, уведомления просто не отправляются.

**Важно:** файл `.env` не должен попадать в git. Проверьте `.gitignore`.

## Развёртывание

Подходит любой хостинг с поддержкой Python. Ниже — на примере Railway.

1. Залейте проект в репозиторий на GitHub
2. На [railway.app](https://railway.app) создайте проект из этого репозитория
3. Добавьте базу: **New → Database → PostgreSQL**
4. В настройках сервиса пропишите переменные окружения из таблицы выше.
   Значение `DATABASE_URL` скопируйте из переменных PostgreSQL
5. В разделе Networking сгенерируйте домен, порт укажите `8080`

Схема базы обновляется автоматически при запуске — отдельные миграции запускать не нужно.

### Смена домена

QR-коды не хранятся файлами, а собираются в момент запроса, поэтому при переезде
на новый адрес они обновятся сами. Но **физические наклейки придётся перепечатать** —
старые ведут на прежний домен. Новые берите со страницы `/qr/print`.

## Перенос данных

Выгрузить с текущего сервера:

```bash
pg_dump "СТАРЫЙ_DATABASE_URL" > geekcult.sql
```

Залить на новый:

```bash
psql "НОВЫЙ_DATABASE_URL" < geekcult.sql
```

Фотографии предметов и аватары хранятся прямо в базе, поэтому переносятся
вместе с дампом. Отдельно копировать ничего не нужно.

## Первый вход

После запуска зайдите под учётной записью из `ADMIN_EMAIL` и `ADMIN_PASSWORD`.
В шапке появится раздел «Админка».

**Сразу смените пароль администратора** в разделе редактирования профиля.

Обычные пользователи регистрируются сами и могут только бронировать
и возвращать вещи. Права администратора выдаются флагом `is_admin`
в таблице `users`.

---

## Известные ограничения

- Восстановление пароля по почте не реализовано — сброс делается через базу
- Фотографии хранятся в базе, что удобно при переездах, но при большом
  количестве предметов имеет смысл вынести их в объектное хранилище
- Картинки локаций в `static/img/` подобраны для конкретного клуба.
  При использовании в другом проекте замените их на свои —
  права на текущие изображения не передаются вместе с кодом
